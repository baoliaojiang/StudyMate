# 里程碑

| 阶段 | 内容 | 状态 |
| --- | --- | --- |
| M1 | Web/PWA 核心：项目 CRUD、四份报告骨架、15 篇研究记录、要求解析、DOCX 导出、模型接入、来源检索、引导页、浅/深色 | **已完成**（构建 + 23 用例通过） |
| M2 | 学校 DOCX 模板导入与样式识别、PDF 导出、章节版本管理、事实一致性校验 | 未开始 |
| M3 | Capacitor 安卓壳（本机 SDK 打包 APK）+ Electron 桌面壳（NSIS EXE）+ 原生分享与加密存储桥接 | 脚手架草案 |
| M4 | 自动推进（带关键节点确认）、工作流可视化编辑器、外部 Skill 导入沙箱 | 未开始 |
| M5 | 免费 API 指引中心（可从 GitHub 配置更新 + 离线缓存）、多学校模板市场 | 未开始 |

## 每阶段的验收标准

- `npm run build` 零错误
- `npm test` 全绿
- 新增能力有对应测试
- 涉及导出时，DOCX 必须通过 ZIP + `word/document.xml` 校验
- 无法验证的东西**不写进「已完成」**
