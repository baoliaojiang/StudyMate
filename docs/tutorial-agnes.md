# 研学帮 StudyMate 使用教程（含 Agnes 免费模型接入）

本教程写于 2026 年 11 月 6 日，对应研学帮 StudyMate v1.0.16。
软件以后还会更新，按钮叫什么、放在哪里都可能变，一切以软件里实际看到的界面为准。
这份教程是写给第一次用这个软件、也完全不懂电脑的同学看的。
不用背东西，不用敲命令，照着一步一步点就行，慢慢来，别着急。
哪里和教程对不上，就照软件里当时显示的文字做，不会弄坏的。

---

## 一、先弄明白这个软件是干什么的

研学帮是帮高中生整理研究性学习材料的工具。
一个课题从开题、平时记录，到中期、结题，四份材料共用同一份资料，不用反复抄。
软件本身不收钱，装在自己电脑上就能用。
软件自己不会动脑子，想让它帮你想句子、写初稿，得先给它接一个「模型」。
「模型」就是替软件动脑子的那部分，本教程接的是一个叫 Agnes 的模型。
它现在有没有免费额度，以平台页面实际显示为准。
你写的课题、记录、报告都只存在这台设备上，不会传到开发者的服务器。
软件不会替你编造做过的调查、访谈和实验，真实内容都要你自己填。
不接模型也能照常写内容、填记录、导出 Word 文件，只是没有 AI 帮忙起草。

## 二、第一次打开，跟着引导走一遍

第一次打开软件，会出现一整屏的「你好」。

1. 点屏幕下方的「继续」。
2. 接下来会依次看到「隐私政策」「用户协议」「声明」三页文字。
3. 每一页都要把文字往下拉到最底下，屏幕上的提示才会变成「已读完，可以继续」。
4. 读完还要再等几秒，等提示变了再往下走，不用抢那几秒。
5. 提示可以了，把这一页下方的方框点一下打勾，再点「继续」。
6. 「声明」那一页有两个方框，两个都要勾，其中一个是知悉 AI 模拟内容是虚拟示例。
7. 走到「外观」，可以选浅色还是深色、字大还是小，选不顺眼以后都能改，不选直接「继续」也行。
8. 走到「使用偏好」，不懂的就保持原样，点「继续」。
9. 走到「接入模型」，这一页可以先跳过，本教程第三节再回来接，点「继续」即可。
10. 后面的「四步走完一个课题」「用哪些技能和助手」是给你看的说明，看完点「继续」。
11. 最后一页是「准备就绪」，点「开始使用」就进到软件首页了。

以后想重看一遍，去「设置 → 帮助 → 其他设置 → 重新引导」，只回看流程，不会删你写过的东西。

## 三、接 Agnes 免费模型（最要紧的一步）

这一步分五小段：先去官网拿一串钥匙，再把钥匙填进软件，然后测试、选模型、排错。

### 3.1 去 Agnes 官网注册，拿到一串钥匙

1. 打开你平时上网用的浏览器。
2. 在最上面那条输入网址的长框里，输入 `https://platform.agnes-ai.com`，按回车。
3. 等页面打开，找到「注册」或「登录」，按页面上的提示一步步填。
4. 注册时要填什么、要不要验证码、要不要绑手机、有没有活动、免费多少，都以平台页面实际显示为准。
5. 本教程不承诺任何免费额度、价格或活动，页面怎么写你就怎么填。
6. 登录进去以后，在页面里找「API Keys」或「API 密钥」这类字样的入口，点进去。
7. 找到「创建」或「新建」之类的按钮，点一下。
8. 名字随便起一个好记的就行，比如「studymate」。
9. 点完屏幕上会出现一串很长的字符，这就是「API Key」，相当于一把钥匙。
10. 这串字符往往只完整显示这一次，立刻选中它、复制下来。
11. 先粘贴到电脑自带的「记事本」里存着，下一步要用。
12. 复制的时候注意别少复制、别多带空格，整串原样用，以平台页面实际显示的为准。

### 3.2 把钥匙填进软件里

1. 回到研学帮，点左侧的「设置」。
2. 往下找到「模型与检索」这一组。
3. 点这一组里的「API 管理中心」。
4. 进来后默认停在「服务商」这一页，点右上方写着「+ 添加」的按钮。
5. 会弹出一个叫「新建模型提供商」的小面板，点它右下角的「直接自定义」。
6. 接着弹出「添加服务商」的表单，照下面几步填就好。
7. 「名称」这一栏填 `Agnes`，只是个名字，方便你认出它。
8. 「接口类型」这一栏点开下拉，选「OpenAI 兼容」（一般在最上面）。
9. 写着「Base URL」的那一栏，也就是填网址的地方，原样填 `https://apihub.agnes-ai.com/v1`。
10. 这串地址照抄，别多打一个斜杠，也别少字母。
11. 「API Key」这一栏，把刚才存的那串字符粘贴进去。
12. 旁边有「显示」按钮，不放心可以点一下看看有没有粘全，看完再点「隐藏」。
13. 下面「该服务商提供模型列表接口」前面的方框，点一下打勾。
14. 检查一遍：名字、网址、钥匙都没错，点最下面的「添加」。
15. 回到服务商列表，会看到多出一行「Agnes」，这一行右边有一个小开关。
16. 新加的这一行默认是关着的，旁边还标着「已停用」。
17. 把这一行右边的开关点一下，让它变亮、变成启用。
18. 这一步千万别漏：开关不开，后面 AI 一直是灰的，怎么点都没反应，这是新手最常卡的地方。

### 3.3 填完，点一下测试连接

1. 在「Agnes」这一行下面，找到「连接测试」按钮，点一下。
2. 屏幕上会一行一行列出检查结果，等它跑完。
3. 每一行都通过，就说明已经接通了。
4. 有哪一行是红的，就说明卡在那一步，红字会写明原因。
5. 通过以后，Agnes 这一行还会留一句「上次检查 · 通过」，方便以后回来看。

### 3.4 告诉软件用哪个模型

1. 在「API 管理中心」最上面一排标签里，点「模型」。
2. 先点 Agnes 那一行里的「同步模型」，让软件把可选的模型拉出来。
3. 要是没拉出来，就在「输入模型名称」的框里填 `agnes-2.5-flash`，再点旁边的「添加」。
4. 在列表里找到 `agnes-2.5-flash` 这一行，点它右边的「校验」。
5. 这一行出现「已校验」三个字，就说明这个模型真能用。
6. 再点这一行的「设为默认」，以后软件就默认用它。
7. 回「设置」首页看一眼，「API 管理中心」右边显示出模型名，就说明接好了。

### 3.5 测试连接失败怎么办

1. 别急，先看红字写的是什么，它会告诉你卡在哪一步。
2. 回「服务商」页点「编辑」，把 `https://apihub.agnes-ai.com/v1` 重新对一遍，一个字母都别差。
3. 把「API Key」重新整串粘贴一次，最常出的毛病就是复制少了一截。
4. 确认「Agnes」这一行右边的开关是亮的、是开着的。
5. 确认「接口类型」选的是「OpenAI 兼容」。
6. 还不行就看看网络通不通、账号那边是不是要再做什么，账户状态与可用范围以平台页面实际显示为准。
7. 改完以后，再点一次「连接测试」，不用重头填。
8. 反复试都不行，先看本教程第十三节的「常见问题」，或者到第十五节的求助入口找人问。

## 四、随便问一句，确认真的能用

1. 点左侧的「对话」。
2. 在页面最下面的输入框里，打一句「你好，用一句话介绍你自己」。
3. 点发送。
4. 看到文字一点点冒出来，就说明模型接好了。
5. 如果看到「AI 不可用 · 未配置模型」，回第三节检查开关和那串钥匙。
6. 没接模型也不影响别的：写内容、填记录、导出 Word 都照常用。

## 五、建一个自己的项目

1. 点左侧的「新建项目」，桌面上方也可能有个「新建」按钮，点哪个都行。
2. 第一步先填「研究主题」，自己写题目就行。
3. 想不出题目，可以点「从备选选题选」挑一个，或点「拿不定主意？AI 帮你想」让 AI 给几个方向。
4. 接着把老师发的要求整段粘贴进「教师布置的研究性学习要求」那个大框里。
5. 没有书面要求，就写一句「老师口头布置，无书面要求」，别空着。
6. 想省事可以点「让 AI 帮我分析要求」，识别出来的内容也要自己逐项看一眼再用。
7. 点「下一步」。
8. 第二步填「指导教师姓名」，这一栏必须自己填，软件不会替你猜人名。
9. 再填「小组成员」，输入名字点「添加」，多个人用逗号或空格分开都行。
10. 学校、年级、班级、小组名称、起止时间，知道的就填，不知道的先留空，建好还能改。
11. 点「下一步」。
12. 第三步选「研究方式」，按你们真实怎么做就选哪个，可以多选。
13. 「AI 工作模式」不懂就保持「AI 辅助」。
14. 「研究记录篇数与学期分配」默认是 15 篇（上学期 8 篇、下学期 7 篇），按学校要求改，不改也行。
15. 点「下一步」。
16. 第四步是一张确认单，把课题、老师、成员、篇数核对一遍。
17. 点「创建项目」，就进到项目页面了。

## 六、日常最推荐的一条路：研究记录

这是本教程最想告诉你的一条路，稳当、好改、不容易出错。

1. 点左侧的「过程记录」，能看到每个项目填了多少篇。
2. 点某个项目，就直接落到这个项目的「研究记录」那一页。
3. 也可以先进项目，再点上方的「研究记录」标签。
4. 这一页是一张卡一篇，按「上学期」「下学期」分好组，卡片上会写「空」「已填」或「已确认」。
5. 找到一张还空着的卡，点卡片下面的「没灵感？让 AI 生成初稿」。
6. 等一下，AI 会先写个草稿进去，卡片变成「已填」。
7. 点这张卡，会打开一整页专门写这一篇，不是小弹窗，地方够大，慢慢改。
8. 把「这次做了什么」「阶段名称」「起迄时间」「地点」「参与成员」改成真实情况。
9. 下面几个大框，按你们真实做了什么、得到什么、下阶段打算做什么，一条条改成自己的话。
10. 有照片、问卷照片，可以点「加附件」放进来，方便自己留底。
11. 改完先点「保存」。
12. 逐条核对过、确认都是真事，再点「保存并确认真实」。
13. 要交这一篇时，点页面底部的「导出 DOCX」，就得到一个 Word 文件。
14. 想自己挑放在哪，点「另存为…」，会弹窗让你选文件夹。
15. 回到卡片上，也有「导出 DOCX」和「另存为」两个按钮，一样能用。
16. 每篇都能单独生成、单独改、单独导出，写错只改那一篇，不会牵连别的。

## 七、四份材料和报告是怎么写出来的

1. 一个项目里有四份材料：开题、研究记录、中期、结题。
2. 进项目后，上方一排标签就能在「开题」「研究记录」「中期」「结题」之间切换。
3. 点「开题」「中期」或「结题」，进到的是报告页。
4. 报告页左边是一列章节名字，点哪一节，右边就写哪一节。
5. 每一节都可以自己写、自己改，也能点「AI 起草本节」让它先写个初稿，再逐句改成自己的话。
6. 章节名字可以「改名」，也能「+ 章节」「导入模板」，按学校表格来就行。
7. 报告有「未开始 / 草稿 / 待审核 / 已确认」几个状态，由你自己往下推。
8. 右边还有「逐节起草（跳过教师栏）」，一口气起草时，老师要填的那一栏会自动跳过。
9. 报告页能点「预览版式」先看一眼，右边「导出」那栏点「DOCX」就存成 Word 文件。
10. 旁边还有 PDF 和另一种纯文字格式，不懂就只点「DOCX」。
11. 项目「概览」页的「交付与导出」里，四份材料可以各自导出成 Word，还能「打包下载」和「导出前核对」。
12. 「答辩 PPT」是可选的，不做也不影响四份材料导出。
13. 「导出前核对」会列出还没处理好的地方，交之前照着清单过一遍最稳妥。

## 八、设置里都能改什么

1. 点左侧「设置」，最上面有你的个人卡片，点进去是账号页。
2. 「外观」里有主题、字体、「字号」和「界面动效」。
3. 「字号」有「小 / 标准 / 大 / 特大」四档，字看不清就调大一档。
4. 「通知」里是几个本地提醒开关，都是提醒自己用的。
5. 「语音」里有「语音播报」开关和「音色与试听」。
6. 「模型与检索」里有「API 管理中心」「检索与来源」「免费 API 指引」，还有每日预算和每日调用次数上限。
7. 「检索与来源」管的是找资料、核对出处的那些服务，不懂可以先不动。
8. 「免费 API 指引」能看到各家服务的官网和取钥匙的办法，额度、价格、活动都以服务商官方页面为准。
9. 「个性化」里有记忆、AI 工作模式、「缺材料时」、打字流速度、深度思考、常用语。
10. 「缺材料时」默认选「留白待补充」，意思是缺事实就让那一节空着、写「待补充」，不替你编数据。
11. 另一档「写满再核对」会把篇幅尽量写满，推断处标「需核实」，交之前必须逐条核对。
12. 「订阅与数据」里有「订阅与用量」「存储与空间」「数据与备份」。
13. 「帮助」里有「帮助中心」「反馈问题」「其他设置」。

## 九、全自动工作流：默认关着，先别开

1. 「全自动工作流」藏在「设置 → 帮助 → 其他设置 → 高级功能」里，默认是关着的。
2. 普通使用根本看不到那个入口，也不用去找它。
3. 它属于高级功能，有风险：会把整套流程一口气跑完，中间只停下来问你要不要确认。
4. 跑的时候面板里常常只看到摘要，正文还是得回项目页一份一份自己核对。
5. 软件也写了它「不推荐」「即将下线」，以后版本可能直接去掉。
6. 真要去开，软件会先弹一页风险说明让你读，读完点「我了解，仍要开启」才会打开。
7. 关掉它不会删任何东西，已经写好的报告和记录都还在。
8. 日常更省事、也更稳的，就是第六节那条路：研究记录 → 空卡片 AI 生成初稿 → 自己改 → 单篇导出。
9. 写错了只改那一篇，比一口气跑完再回头找错轻松得多。

## 十、几条要记牢的规矩

1. AI 生成的内容只是草稿，只作参考，不能照抄就交。
2. 数据、结论、引用、参考文献，都必须你自己一条条核实过。
3. 没做过的调查、没访过的人、没做过的实验，不能写成「已完成」，没做就照实写「尚未开展」。
4. 学校表格里「指导教师意见」这类栏目，软件不代写、不代签，留空是正常的，打印出来请老师本人写。
5. 检索到的资料只是线索，打开原文确认过再引用，查不到的就标「待核实」。
6. 带「AI 模拟示例」标记的内容是虚拟示例，不能当真实成果提交，标记也别去掉。
7. 导出成 Word 之前，自己把全文完整读一遍，再交给老师。

## 十一、数据与备份，换设备前一定先做

1. 你的项目、报告、记录默认只存在这台设备上，不上传开发者服务器。
2. 换电脑、换手机、清理浏览器数据、卸载软件，都可能让这些内容找不回来。
3. 点「设置 → 订阅与数据 → 数据与备份」。
4. 先在「备份口令」里自己设一个口令，至少要 8 位，位数不够软件会提醒你。
5. 这个口令软件不会保存在任何地方，忘了就打不开备份文件，谁也找不回，也没有后门。
6. 口令设好记牢，点「导出全部数据」旁边的「导出」，会得到一个加密的备份文件，落在默认的下载文件夹，自己放好。
7. 想自己选存到哪里，就点旁边的「另存为」，会弹出系统的保存窗口，挑好文件夹再保存。
8. 到新设备上，点「从备份恢复」旁边的「选择文件」，选这个备份、填同一个口令，就能恢复。
9. 恢复是覆盖式的：会先清空这台设备上现有的数据，再写入备份，动手前先想清楚。
10. 只想搬模型配置，也可以用「导出密钥备份」和「导入密钥备份」，它们同样有「另存为」。
11. 「一键清档」是危险操作，要连着确认三次，删了就没有了，别随便点。

## 十二、检查更新和反馈问题

1. 每次打开软件，它都会自己去查一次有没有新版本，不用你点。
2. 查到新版时，屏幕中间会弹出一个窗口，上面写着新版本号和这一版改了什么。
3. 这个窗口不能用点旁边空白的办法关掉，也不影响你读它上面的更新说明。
4. 想现在更新，点「去更新」，会用浏览器打开新版本的下载直链；不想更新，点「下次再说」，这次打开就不再打扰你。
5. 软件不会自己下载、更不会自己装上，要不要更新由你决定；个别标了「必须升级」的版本，窗口上会只留「去更新」。
6. 平时想主动查一次，点「设置 → 帮助 → 其他设置 → 检查更新」，再点里面的「检查更新」按钮。
7. 网络不通时会如实说明读不到，也可以直接打开下载页看。
8. 遇到想反馈的问题，点「设置 → 帮助 → 反馈问题」。
9. 把「发生了什么、在哪个页面、你本来想要什么」写进框里，点「复制反馈内容」。
10. 再把内容发到第十五节的 QQ 群或仓库 Issue 里，别把那串 API Key 贴进去。

## 十三、常见问题

### 1. 没配模型，会怎样

1. 不影响写内容、填记录、导出 Word，这些照常能用。
2. 只是 AI 起草、AI 帮想题目、检索这些功能用不了。
3. 界面上会显示「AI 不可用 · 未配置模型」，这是在提醒你还没接模型，不是坏了。
4. 想用 AI，回第三节照着接一次就好。

### 2. AI 没反应、一直是灰的

1. 先看「设置 → 模型与检索 → API 管理中心」里，Agnes 那一行右边的开关是不是开着。
2. 这一行显示「已停用」，就是开关没开，点一下让它变亮，这是最常见的原因。
3. 再点这一行的「连接测试」，看是哪一行红了、红字写了什么。
4. 接着看网址是不是 `https://apihub.agnes-ai.com/v1`，一个字母都别差。
5. 再看那串钥匙是不是整串粘全了，不放心就重新复制粘贴一次。
6. 也看看「模型」页里 `agnes-2.5-flash` 是不是「已校验」、有没有「设为默认」。
7. 还不行就看看网络通不通、账号那边有没有要补的步骤，账户状态以平台页面实际显示为准。
8. 改一样就再点一次「连接测试」，不用从头填。

### 3. 导出的文件找不到

1. 电脑上直接点「导出 DOCX」，文件一般落在系统默认的「下载」文件夹里，先去那里翻。
2. 点「另存为…」时，会弹窗让你自己挑文件夹，挑了哪里就去哪里找。
3. 想不起来放哪了，就重新点一次「另存为…」，这回挑一个记得住的位置，比如桌面。
4. 文件名里带着课题名和材料名，按名字搜一下也找得到。
5. 导出完软件会弹一句提示，说「已保存到默认下载文件夹」或「已保存到你选的位置」，照着提示找。

### 4. 备份口令忘了

1. 找不回来，软件不保存口令，也没有后门，开发者也没法替你解开。
2. 那份备份文件只能先放好，别删，说不定哪天又想起来了。
3. 以后设口令时，挑一句自己肯定记得、又不容易被别人猜到的话，至少 8 位，记在纸上也行。
4. 要是原来的数据还在软件里，可以重新设一个新口令、重新导出一份新备份。

### 5. 网页版和电脑版的数据不互通

1. 数据只存在各自那台设备、那个浏览器里，不上传、也不自动同步。
2. 在网页版里建的项目，装到电脑上的软件里看不到，反过来也一样。
3. 两边各自是独立的一份，别指望这边写、那边自动出现。
4. 想搬过去，就用第十一节的「导出全部数据」和「从备份恢复」，用同一个口令搬。
5. 清理浏览器数据或卸载应用，本机的那一分会一起消失，重要内容记得先备份。
6. 那串 API Key 也建议只在自己装好的软件里填，公用的、别人的设备别填。

### 6. 安卓端保存的文件在哪

1. 点「导出 DOCX」，文件会直接存进手机的「下载 / StudyMate」文件夹，屏幕上也会提示存好了。
2. 点「另存为」，会弹出系统的保存窗口，可以自己选文件夹、也能改文件名，选好再点保存。
3. 想发给别人，点「分享」，在弹出来的系统菜单里选微信、QQ 或邮件，把文件发给自己或发到电脑。
4. 备份文件也是一样的：「导出」进下载文件夹，「另存为」自己选位置；「选择文件」会打开手机的文件管理器让你挑备份。
5. 找不到文件时，打开手机自带的「文件管理」，进「下载 / StudyMate」，按文件名搜一下。
6. 如果屏幕上弹出的是一句失败提示，把那句话原样记下来，到第十五节的 QQ 群里问，别反复乱点。
