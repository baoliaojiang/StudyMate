# 研学帮 StudyMate 小白使用教程（含 Agnes 免费模型接入）

> **这份教程写于 2026 年 11 月 6 日。**
> 软件版本按 v1.0.14 写；Agnes 的免费额度、模型名、网址随时可能变，
> 一切以它官网（https://agnes-ai.com）当时显示的为准。照着做对不上时，先看第八节「对不上怎么办」。

---

## 零、先弄清楚这是两件事

1. **装软件**：研学帮 StudyMate 本身不花钱，装上就能用界面。
2. **接模型**：软件自己不会「思考」，要接一个 AI 服务。Agnes 现在提供免费额度，所以我们接它。

顺序不能反：先接模型，软件里的 AI 功能才会从灰色变亮。

---

## 一、去 Agnes 注册，拿一串 Key

1. 用浏览器打开 **https://platform.agnes-ai.com**。
2. 点注册 / 登录。支持邮箱、Google、GitHub，**不用手机号**。
3. 登录后，看左侧菜单，找到 **API Keys**（有的界面叫「API 密钥」）。
4. 点 **Create / 创建**，名字随便写，比如 `studymate`。
5. 生成后会出现一串以 `sk-` 开头的字符。**立刻复制**，它只显示这一次。丢了只能删掉重建。
6. 把这串字符先粘贴到你的记事本里，下一步要用。

> 记不住网址就记这句：`platform.agnes-ai.com` 是「注册和管理 Key 的地方」，
> `apihub.agnes-ai.com` 是「软件要填的地址」。两个不是同一个东西。

---

## 二、把软件装上

三选一，别都装：

- **Windows**：到 https://github.com/baoliaojiang/StudyMate/releases 下载
  `StudyMate-1.0.14-setup.exe`，双击下一步下一步。第一次打开 Windows 可能弹「已保护你的电脑」，
  点「更多信息 → 仍要运行」。
- **不想装**：直接用在线版 https://baoliaojiang.github.io/StudyMate/ ，用浏览器打开就能用。
  缺点是重装浏览器后本地数据会没，建议还是装。
- **安卓手机**：在同一页面下载 `StudyMate-1.0.14-release.apk`，用手机打开安装。
  会提示「未知来源」，允许一次即可；这是自签名包的正常提示。

装完打开，会先出一个欢迎页，点进去就行。

---

## 三、把 Key 填进软件（最关键的一步）

1. 底部/侧边找到 **设置**（齿轮图标）。
2. 进 **模型与检索** → **API 管理中心**。
3. 切到 **服务商** 这一栏，点右上角 **+ 添加**。
4. 列表里选 **OpenAI Compatible**（意思是「兼容 OpenAI 写法」，Agnes 就是这种）。
5. 会出来一个表单，只改两个地方：
   - **名称**：写 `Agnes`
   - **接口地址 / Base URL**：填

     ```
     https://apihub.agnes-ai.com/v1
     ```

     一个字母都别少，结尾的 `/v1` 必须带上，不要在最后加斜杠。
   - **API Key**：粘贴第一步那串 `sk-...`
6. 点 **保存**。
7. **重要**：保存后服务商那一行右边有个开关，把它**打开**。
   不打开的话，AI 功能仍然是灰的——这是新手最常卡住的地方。

> 如果上面那个地址一直转圈失败，可以试国内节点：
> `https://apihub.agnes-ai.cn/v1`
> 这个地址来自第三方教程，我没替你逐个验证；不通就换回上面那个。

---

## 四、告诉软件「用哪个模型」

1. 还在 API 管理中心，点你刚建的 **Agnes** 那一行，进 **模型** 页。
2. 有两种做法：
   - 点 **同步模型列表**，让它自己拉；
   - 或者手动：在输入框写

     ```
     agnes-2.5-flash
     ```

     点 **添加**。
3. 加完点这一行的 **校验 / 测试**。看到「可用」就成功了；失败看第八节。
4. 回到软件顶部（电脑）或首页（手机），点 **模型选择** 那个按钮，选中 `agnes-2.5-flash`。

到这里，AI 就算接好了。

---

## 五、验证一下真的能用

1. 回首页，在对话框里发一句：`你好，用一句话介绍你自己`。
2. 正常表现：先出现三个点，然后文字一个字一个字冒出来。
3. 如果提示「AI 不可用 · 未配置模型」，说明第三节第 7 步的开关没开，回去打开。

---

## 六、建第一个项目

1. 首页点 **新建项目**。
2. **研究主题**：自己写，或者点 **从备选选题选**，也可以点 **拿不定主意？AI 帮你想** ——
   写一句你在意的事（比如「食堂剩饭很多」），它会给几个能直接开做的题目。
3. **教师布置的研究性学习要求**：把老师发的通知、表格要求，原封不动粘进去。
   没有书面要求就写「老师口头布置，无书面要求」，别空着。
4. 点 **让 AI 帮我分析要求**，它会认出学校、篇数、时间节点。识别结果要你逐项确认，确认完再往下。
5. 后面几步填指导教师姓名、成员、研究方式。**教师姓名必须自己填，软件不会替你猜。**
6. 最后一步点 **创建**。

---

## 七、跑「项目推进」（会写四份材料和过程记录）

1. 进项目 → 点 **项目自动推进**。整个流程现在是 22 步，其中 7 处会停下来等你确认。
2. 从上往下走。**每一处「等你确认」都要你自己看一遍再点确认**，软件不会替你确认。
3. 走到「上学期过程记录」时，它会**一次写 3 篇**，写完存 3 篇，再写下一批。
   这是故意的：一次写十几篇既慢又容易写飘。
   - 如果中途到了调用次数上限，它会停下来说「还差 N 篇」，点继续会**接着写，已写好的不重复**。
4. **这批记录是「按计划该做的事」，不是已经发生的事。** 生成完是「未确认」状态。
   你要到「过程记录」里逐篇改成真实时间、真实参与人、真实做法，再点 **确认真实**。
   没确认的记录，后面的「核对记录」会拦住你，这是对的——别去绕它。
5. 一直走到「导出 DOCX」，按学校表格导出。交之前自己通读一遍。

## 八、对不上怎么办

| 你看到的 | 多半是什么原因 | 怎么办 |
|---|---|---|
| AI 功能一直是灰的 / 「未配置模型」 | 服务商开关没打开 | 设置 → API 管理中心 → 打开右侧开关 |
| 保存说 401 / Unauthorized | Key 复制少了字符，或已经被删 | 回 Agnes 重新创建一个 Key，整串覆盖粘贴 |
| 404 / model not found | 模型名写错 | 只填 `agnes-2.5-flash`，别加前缀空格 |
| 一直转圈、超时 | 地址写错或网络不通 | 确认 Base URL 是 `https://apihub.agnes-ai.com/v1`；换个网络试 |
| 429 / 提示限流 | 免费额度有每分钟请求上限，点太快了 | 等一会儿；顶栏会出现「立即重试」，点它就不用等满 60 秒 |
| 推进到某步失败 | 那一步缺前置材料 | 看红字提示，它会告诉你缺什么、去哪补 |
| 写到一半停下来说还差 N 篇 | 到本次调用上限了 | 点继续，会接着写；想要一次写完，去设置里把「单次任务调用上限」调高 |

> 免费额度的常见限制：每分钟大约 30 次请求、不需要绑卡、官方说无限期免费。
> 这是 2026-11-06 的情况，之后以官网为准。请求太密就慢一点，别连点。

## 九、几件要提前知道的事

1. **记录不能编。** 软件只帮你把该做的事排成流水，真实数据、访谈、实验结果要你自己填。
   没做的就写「未做」，别为了凑篇数编。
2. **教师意见留空是正常的。** 那一栏是老师写的，软件不代写，导出前检查也不会拦你。
3. **备份。** 数据都在你自己电脑里（设置 → 数据与备份），换电脑前先导出一份。
4. **反馈与授权**：问题进 GitHub Issues 或 QQ 群 1134731856；
   商用与对外分发要先在群里说明用途拿授权，自己学校免费用不用授权。
