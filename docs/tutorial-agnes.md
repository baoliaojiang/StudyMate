# 研学帮 StudyMate 小白使用教程（含 Agnes 免费模型接入）

> **写于 2026 年 11 月 6 日**，对应软件 v1.0.15。
> Agnes 的免费额度、模型名、网址会变，以它官网当时显示为准。

---

## 零、先分清两件事

1. **装软件**：软件本身不收钱。
2. **接模型**：软件自己不会思考，要接一个 AI 服务。Agnes 现在有免费额度，我们接它。

先接模型，AI 功能才会从灰色变亮。

## 一、注册 Agnes，拿一串 Key

1. 浏览器打开 **https://platform.agnes-ai.com**。
2. 注册 / 登录，支持邮箱、Google、GitHub，**不用手机号**。
3. 左侧菜单找 **API Keys**（或「API 密钥」）。
4. 点 **Create / 创建**，名字随便写，比如 `studymate`。
5. 生成后出现一串以 `sk-` 开头的字符，**立刻复制**——只显示这一次。
6. 先粘到记事本，下一步要用。

> 两个域名不一样：`platform.agnes-ai.com` 是注册和管理 Key 的地方，`apihub.agnes-ai.com` 是填进软件的地址。

## 二、装软件（三选一）

- **Windows**：https://github.com/baoliaojiang/StudyMate/releases 下 `StudyMate-1.0.15-setup.exe`，双击下一步。弹「已保护你的电脑」→ 更多信息 → 仍要运行。
- **不想装**：直接开 https://baoliaojiang.github.io/StudyMate/ 。缺点：清浏览器数据后本地内容会没。
- **安卓**：同页面下 `StudyMate-1.0.15-release.apk`，允许「未知来源」一次。

## 三、把 Key 填进软件（最容易卡的一步）

1. 左下 **设置**。
2. 找到 **模型与检索** 分组 → 点 **API 管理中心**。
3. 切到 **服务商**，点右上 **+ 添加**。
4. 选 **OpenAI Compatible**。
5. 只改三处：
   - 名称：`Agnes`
   - 接口地址：`https://apihub.agnes-ai.com/v1`（`/v1` 必须有，结尾别加斜杠）
   - API Key：粘贴 `sk-...`
6. 点 **保存**。
7. **保存后把这一行右边的开关打开**。不开，AI 功能一直是灰的——这是新手最常卡的地方。

> 上面地址一直失败，可试国内节点 `https://apihub.agnes-ai.cn/v1`（来自第三方教程，未逐一验证，不通就换回来）。

## 四、告诉软件用哪个模型

1. 点 **Agnes** 那行进 **模型** 页。
2. 点 **同步模型列表**，或手动输入 `agnes-2.5-flash` 后点 **添加**。
3. 点 **校验**，看到「可用」就成了。
4. 回顶部点 **模型选择**，选中 `agnes-2.5-flash`。

## 五、验证能用

首页发一句「你好，用一句话介绍你自己」。正常是三个点 → 文字一个个冒出来。
提示「AI 不可用 · 未配置模型」= 第三节第 7 小步没做。

## 六、建第一个项目

1. 左侧 **新建项目**。
2. 研究主题：自己写，或 **从备选选题选**，或点 **拿不定主意？AI 帮你想**。
3. 教师要求：把老师发的通知、表格要求原样粘进去；没有就写「老师口头布置，无书面要求」，别空着。
4. 点 **让 AI 帮我分析要求**，识别结果逐项确认。
5. 填指导教师姓名（**必须自己填**）、成员、研究方式。
6. **创建**。

## 七、跑「项目推进」（22 步）

1. 进项目 → **项目自动推进**。7 处会停下来等你确认。
2. 每个「等你确认」都要自己看一遍再点，软件不替你确认。
3. 到 **上学期过程记录**：一次填 3 篇、存 3 篇，界面上能看到写到第几篇。
   - 到本次调用上限会停下说「还差 N 篇」，点继续接着填，**已填好的不重复**。
   - 它填的是项目创建时就建好的那几篇空白记录，不会凭空多出一批。
4. **这批是「按计划该做的事」，不是已经发生的**。去「过程记录」逐篇改成真实时间、真实参与人、真实做法，再点 **确认真实**。
   没确认，下一步「核对上学期记录」会拦住你——这是应该的。
5. 走到 **导出 DOCX**，按学校表格导出，交前自己通读。

### 跑错了怎么办：回退

任意一步点开，底部有 **回退到这一步**。

- 点了会先弹确认，写清删什么：这一步到最后一共几步、要删哪几份报告的正文、要清哪个学期的记录草稿。
- 确认后：**这一步及之后所有步骤的产物被删除**，状态回到「等待」；报告退回「未开始」；记录清回空白（篇数、编号不变）。
- 删了不能撤销。想好了再点；然后点 **继续** 从这一步重新跑。

## 八、设置里都有什么

| 分组 | 你能改什么 |
|---|---|
| 外观 | 主题（跟随系统/浅色/深色）、字体、**字号**（小/标准/大/特大）、界面动效开关 |
| 通知 | 阶段截止、每周小结、AI 完成提示、系统更新提示（都是本地提醒） |
| 模型与检索 | API 管理中心、检索与来源、免费 API 指引、每日预算、每日调用上限 |
| 个性化 | 记忆开关、AI 工作模式（辅助/主导）、**缺材料时**（留白待补充 / 写满再核对）、**打字流速度**、**深度思考**、常用语 |
| 订阅与数据 | 订阅与用量、存储与空间、数据与备份 |
| 帮助 | 帮助中心、反馈问题、其他设置（关于、更新、协议、重新引导、开发者选项） |

「缺材料时」选 **留白待补充** = 缺事实就让那一节空着、写「待补充」，不编数据。
「写满再核对」= 尽量写满，但推断处标「需核实」、数据留横线、结尾带免责声明。

## 九、对不上怎么办

| 现象 | 原因 | 做法 |
|---|---|---|
| AI 一直是灰的 | 服务商开关没开 | 打开那一行右侧开关 |
| 401 | Key 复制少了字符，或已删 | 重新建 Key，整串覆盖粘贴 |
| 404 model not found | 模型名写错 | 只填 `agnes-2.5-flash` |
| 一直转圈 | 地址错或网络不通 | 核对 `https://apihub.agnes-ai.com/v1` |
| 429 限流 | 免费版约每分钟 30 次 | 等一下；顶栏点「立即重试」不用等满 60 秒 |
| 推进某步失败 | 缺前置材料 | 看红字，它写明了缺什么、去哪补 |
| 说还差 N 篇 | 到本次调用上限 | 点继续；或到 模型与检索 调高每日上限 |
| 记录还是空的 | 起草被打断 | 点「只重跑这一步」，会接着填空着的那些篇 |

## 十、提前知道几件事

1. **记录不能编**：软件只帮你排流水，真实数据要自己填，没做就写「未做」。
2. **教师意见留空正常**：那栏是老师写的，不代写、检查也不拦。
3. **备份**：数据都在本机（设置 → 数据与备份），换电脑前先导出。
4. **反馈与授权**：Issues 或 QQ 群 1134731856；商用与对外分发先在群里说明用途，自己学校免费用不用授权。
