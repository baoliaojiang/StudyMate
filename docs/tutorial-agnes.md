# 研学帮 StudyMate 使用教程

写于 2026 年 11 月 7 日，对应 v1.0.18。

软件还在更新，按钮的位置和叫法以后可能变。真到了对不上的时候，以屏幕上看到的为准。照着点不会把东西弄坏，这一点可以先放心。

这份教程假设你第一次用，也没写过研究性学习。不需要背，也不需要懂技术，一步一步往下走就行。

---

## 一、这软件到底是干什么的

高中生做研究性学习，最后要交几份材料：开题报告、过程记录、中期报告、结题报告。四份东西说的是同一个课题，内容互相咬合。学校通常还会发固定的表格。

研学帮管的就是这件事。课题信息填一次，后面记录、报告都从这一份资料里取，不用每份材料重抄一遍。

软件装在自己设备上，项目、记录、报告都存在本地，不上传开发者的服务器。

它本身不会写东西。想让它帮你想句子、起草初稿，得先接一个模型。模型就是替你动脑子的那一部分，接谁的都行。本教程用 Agnes 举例，因为它有免费额度，接起来简单。

不接模型也能用。填记录、写报告、导出 Word 都照常，只是没有 AI 帮忙。

## 二、第一次打开，把引导走完

第一次打开会出现一整屏的「你好」。

1. 点「继续」。
2. 接下来三页：隐私政策、用户协议、声明。
3. 每一页都要把文字拉到最底。拉到最底，底下的提示才会变成「已读完，可以继续」。
4. 提示变了以后，页面上还会再等几秒才能点。不用抢，正好趁这几秒看一眼写了什么。
5. 勾上页面下方的方框，点「继续」。
6. 「声明」那一页有两个框，两个都要勾。其中一个说的是：AI 生成的模拟内容属于虚拟示例。
7. 到「外观」，浅色深色、字大字小，随手选一个。以后能改。
8. 到「使用偏好」，看不懂就保持原样。
9. 到「接入模型」可以先跳过，第三节再回来接。
10. 后面两页「四步走完一个课题」「用哪些技能和助手」是说明，看完点「继续」。
11. 最后一页点「开始使用」，进首页。

想再看一遍，去「设置 → 帮助 → 其他设置 → 重新引导」。只重走流程，不会删你写的东西。

## 三、接一个模型（Agnes）

这一段分五步：拿钥匙、填进软件、测连接、选模型、排错。新手最常卡在前两步，慢一点。

### 3.1 去官网拿一串钥匙

1. 打开平时上网的浏览器。
2. 地址栏输入 `https://platform.agnes-ai.com`，回车。
3. 页面上找「注册」或「登录」，按提示填。
4. 要不要手机号、要不要验证码、有没有免费额度，都按页面当时写的来。本教程不承诺价格，也不承诺额度，页面怎么写就怎么弄。
5. 登录后找「API Keys」「API 密钥」这类入口，点进去。
6. 点「创建」或「新建」。
7. 名字随便起，比如 `studymate`，只是方便你自己认。
8. 点完会出来一长串字符，这就是钥匙。
9. 这串东西一般只完整显示这一次。立刻全选、复制。
10. 先粘到记事本里存着，下一步要用。别多复制空格，也别少一截。

### 3.2 把钥匙填进软件

1. 回到研学帮，左侧点「设置」。
2. 找「模型与检索」这一组，点「API 管理中心」。
3. 默认停在「服务商」页，点右上角的「+ 添加」。
4. 弹出「新建模型提供商」，点右下角「直接自定义」。
5. 「名称」填 `Agnes`。
6. 「接口类型」下拉，选「OpenAI 兼容」。
7. 「Base URL」填 `https://apihub.agnes-ai.cn/v1`。
8. 这串地址别多打斜杠，也别改字母。少一个字符就连不上。
9. 「API Key」把刚才那串粘进去。
10. 旁边有「显示」，不放心点开看一眼，确认没粘漏，再点「隐藏」。
11. 勾上「该服务商提供模型列表接口」。
12. 从头到尾看一遍：名字、地址、钥匙。点最下面的「添加」。
13. 回到列表，会多出一行 Agnes。它默认是关着的，右边写着「已停用」。
14. 点这一行右边的开关，让它亮起来。

第 14 步千万别漏。开关不开，后面 AI 一直是灰的，怎么点都没反应，这是问得最多的一类问题。

### 3.3 测一下通不通

1. Agnes 那一行下面有「连接测试」，点它。
2. 屏幕上会一行一行出结果。等它跑完。
3. 全绿就是通了。
4. 有红行，红字会写卡在哪。照着红字改，不用重头填。

### 3.4 选一个模型

1. 在「API 管理中心」顶上一排标签里点「模型」。
2. 找到 Agnes 那一行，点「同步模型」，让它把能用的模型列出来。
3. 同步不出来，就在「输入模型名称」里手填一个，再点「添加」。本教程实测可用的是 `agnes-3.0-flash`。
4. 在列表里找到它，点右边的「校验」。
5. 出现「已校验」，说明这个模型真能用。
6. 点「设为默认」。
7. 回设置首页，「API 管理中心」右边会显示模型名。看到名字就是接好了。

### 3.5 连不上怎么排查

看红字，它会告诉你断在哪儿。然后按这个顺序对：

- Base URL 是不是 `https://apihub.agnes-ai.cn/v1`。
- 钥匙是不是整串。这个最容易错，重新复制一次比什么都快。
- Agnes 那一行的开关是不是亮的。
- 接口类型是不是「OpenAI 兼容」。
- 网络通不通。有些网络环境下 Agnes 会慢，等一会儿再测。

改一样就再测一次，不用重填表单。

## 四、问一句，确认能用

1. 左侧点「对话」。
2. 底部输入框打「你好，用一句话介绍你自己」。
3. 点发送。
4. 文字一点点冒出来，就说明通了。
5. 看到「AI 不可用 · 未配置模型」，回第三节查开关和钥匙。

到这一步接不通也不影响别的。第五、六节的内容没有 AI 也能做。

## 五、建一个自己的课题

1. 左侧点「新建项目」。
2. 第一步填「研究主题」。自己会写就直接写。
3. 想不出题目，点「从备选选题选」，或者点「拿不定主意？AI 帮你想」。
4. 下面那个大框，把老师发的要求整段粘进去。
5. 没有书面要求，就写「老师口头布置，无书面要求」。别留空。
6. 嫌麻烦可以点「让 AI 帮我分析要求」，但识别出来的每一项都要自己看一眼。
7. 点「下一步」。
8. 「指导教师姓名」自己填。软件不猜人名。
9. 「小组成员」输入名字点「添加」。多个人用逗号或空格隔开都行。
10. 学校、年级、班级、小组名、起止时间，知道就填，不知道先空着，建完能改。
11. 点「下一步」。
12. 选「研究方式」。你们实际怎么做的就选哪个，能多选。
13. 「AI 工作模式」不懂就留「AI 辅助」。
14. 「研究记录篇数」默认 15 篇，上学期 8 篇、下学期 7 篇。学校有要求就改。
15. 点「下一步」。
16. 最后是一张确认单，把课题、老师、成员、篇数对一遍。
17. 点「创建项目」。

进去以后，顶上有一排标签：概览、开题、研究记录、中期、结题、来源、成员、设置。之后所有事都在这里做。

## 六、写研究记录（最推荐的一条路）

一个课题的骨架就是这些记录。记录写扎实了，中期和结题基本是把记录重新组织一遍。

1. 进项目，点上方「研究记录」。
2. 页面一张卡一篇，按上学期、下学期分好组。卡片上标「空」「已填」「已确认」。
3. 找一张空卡，点下面的「没灵感？让 AI 生成初稿」。
4. 等的时候不用干看着。上方会一条条列它在干什么：收集项目信息、读前序记录、确认要承接的下一步、调用模型、校验、写入。旁边还有已用秒数，数字在动就是没卡。
5. 写完卡片变「已填」。它会接着上一篇的「下阶段研究工作安排」往下写，所以越往后越连贯。
6. 上学期最后一篇的下一步，会自动收在「撰写中期报告」；全项目最后一篇收在「撰写结题报告」。这是软件替你兜的底。
7. 点这张卡，会打开一整页专门写这一篇。不是小弹窗，地方够大。
8. 「阶段名称」「起迄时间」「地点」「参与成员」改成真实情况。
9. 「记录人」「记录时间」看一眼。默认是组长和今天，不对就改。
10. 下面几个大框，按你们真做了什么、拿到什么、下一步干什么，逐句改成自己的话。
11. AI 不会往里写「尚未开展」「待补充」这类空话，每栏都会有内容。但有没有这回事，还得你自己判断。
12. 有问卷照片、活动照片，点「加附件」放进来，方便留底。
13. 想先看交上去什么样，点底部「预览 DOCX」。会弹出一整页白纸黑字，手机上也放得下。
14. 正文里要是还留着「（推断，需核实）」这类标注，点「清理 AI 标注」。会先弹窗警告，确认后一次清掉。清完记得保存。
15. 改完点「保存」。
16. 逐条核对过，确认都是真事，再点「保存并确认真实」。这一步别忘了，没确认的记录在报告里只能当参考。
17. 要交这一篇，点「导出 DOCX」。存好后软件会告诉你存在哪。
18. 想自己挑位置，点「另存为…」。
19. 安卓手机上还能点「分享」，直接发到微信或 QQ。
20. 回到卡片，也有「导出 DOCX」「另存为」「预览」三个按钮。

每篇独立生成、独立修改、独立导出。写错只改那一篇，不牵连别的。

## 七、四份报告

1. 项目里一共四份材料：开题、研究记录、中期、结题。
2. 点上方「开题」「中期」「结题」，进的是报告页。
3. 左边一列章节名，点哪节，右边写哪节。
4. 每节都能自己写，也能点「AI 起草本节」先出个初稿，再逐句改。起草时同样显示步骤和用时；开始前会把课题名发给公开学术检索服务查一次文献，查到的只当线索并标「待核实」，不会自动进你的来源表。不想让它查，把右边「起草前先检索相关文献」的勾去掉。
5. 中期报告只读上学期的记录，结题报告读整个周期，不会把没发生的事写进去。
6. 开题报告写的是计划，不是总结。它会用「计划」「拟」「将」这类说法，不会给你写一堆「尚未开展」。
7. 记录还没写完就想生成中期或结题，软件会拦住，并告诉你还差几篇、缺的是第几篇。右边「写作前检查」顶上有一条进度线，随时能看到记录写到哪了。这不是故障，是防止你把半截项目写成完整报告。
8. 缺真实数据的地方，它会留「待补充：缺什么」。这不是偷懒，是让你自己补。
9. 章节名能改，也能「+ 章节」「导入模板」，按学校表格来。
10. 报告有「未开始」「草稿」「待审核」「已确认」四个状态，自己往下推。
11. 右边有「逐节起草（跳过教师栏）」。一口气起草时，老师要填的那栏会自动跳过。
12. 点「预览版式」能先看一眼排版。
13. 导出栏里点「DOCX」存档。旁边还有 PDF 和 Markdown，不懂就只点 DOCX。
14. 正文里留了 AI 标注，页面上有「清理 AI 标注」，先警告再删，删了不能撤销。
15. 项目「概览」最下面有「交付与导出」：四份材料各自导出 Word、打包下载、导出 Markdown、预览研究记录。点完都会告诉你存哪了。
16. 同一处还有「导出前核对」，列出没处理好的地方。交之前照着过一遍。
17. 「答辩 PPT」是可选的。不做也不影响四份材料导出。

## 八、设置里能改什么

1. 左侧点「设置」。最上面是你的个人卡片，点进去是账号页。
2. 「外观」里有主题、字体、字号、界面动效。
3. 字号四档：小、标准、大、特大。看不清就调大一档，整篇文字都会跟着变。
4. 「通知」是几个本地提醒开关，提醒自己用的。
5. 「语音」里有语音播报开关和音色试听。
6. 「模型与检索」里有「API 管理中心」「检索与来源」「免费 API 指引」，还有每日预算。
7. 「检索与来源」管的是找资料、核对出处。不懂可以先不动。
8. 「免费 API 指引」列了各家服务的官网和取钥匙的办法。额度价格以服务商页面为准。
9. 「个性化」里有记忆、AI 工作模式、「缺材料时」、起草前先检索、打字速度、深度思考、常用语。
10. 「缺材料时」默认「留白待补充」：缺事实就写「待补充」，不替你编数据。
11. 另一档「写满再核对」会把篇幅写满，推断处标「需核实」，交前必须逐条核对。
12. 「订阅与数据」里有「订阅与用量」「存储与空间」「数据与备份」。
13. 「帮助」里有「帮助中心」「反馈问题」「其他设置」。

## 九、自动工作流，默认关着

1. 它藏在「设置 → 帮助 → 其他设置 → 高级功能」里，默认关闭。
2. 普通使用不用碰它。
3. 它会把整套流程一口气跑完，中间只停几次让你确认。
4. 跑的时候面板里多是摘要，正文还是得回项目页一份份核对。
5. 软件自己也标了「不推荐 · 即将下线」。
6. 真要开，会先弹一页风险说明，读完点「我了解，仍要开启」。
7. 关掉它不删任何东西，写好的报告和记录都在。
8. 日常更稳的是第六节那条路：空卡片 → AI 初稿 → 自己改 → 单篇导出。

## 十、几条要记牢的

1. AI 写的是草稿，不能照抄就交。
2. 数据、结论、引用、参考文献，都要自己核实。
3. 没做过的调查、没访过的人、没做过的实验，不能写成已完成。
4. 「指导教师意见」这类栏目，软件不代写、不代签。留空是正常的，打印出来请老师写。
5. 检索到的资料只是线索，打开原文确认过再引。查不到实处的标「待核实」。
6. 带「AI 模拟示例」标记的是虚拟内容，不能当成果提交，标记也别删。
7. 导出 Word 之前，自己完整读一遍。

## 十一、备份：换设备之前一定要做

1. 项目、报告、记录只存在这台设备上。
2. 换电脑、换手机、清浏览器数据、卸载软件，都可能让它们消失。
3. 点「设置 → 订阅与数据 → 数据与备份」。
4. 先设「备份口令」，至少 8 位。
5. 这个口令软件不保存。忘了就打不开备份，没有后门，开发者也没法帮你解。
6. 口令记牢，点「导出全部数据」旁的「导出」。会得到一个加密文件，落在下载文件夹。
7. 想自己选位置，点「另存为」。
8. 到新设备，点「从备份恢复」旁的「选择文件」，选这个文件，填同一个口令。
9. 恢复是覆盖式的：先清空现有数据，再写进备份。动手前想清楚。
10. 只想搬模型配置，用「导出密钥备份」「导入密钥备份」，同样有「另存为」。
11. 「一键清档」要连确认三次，删了找不回来。

## 十二、检查更新和反馈

1. 每次打开软件，它会自己查一次新版本。
2. 查到就弹窗，上面写着版本号和这一版改了什么。
3. 这个窗点旁边关不掉。不影响你读上面的说明。
4. 想更新点「去更新」，用浏览器打开下载直链。不想更新点「下次再说」。
5. 软件不会自己下载、也不会自己装。个别版本标了必须升级，那种窗口上只留「去更新」。
6. 想主动查，去「设置 → 帮助 → 其他设置 → 检查更新」。
7. 网络不通时它会如实说读不到，也会给你下载页。
8. 要反馈问题，点「设置 → 帮助 → 反馈问题」。
9. 写清楚：在哪个页面、做了什么、本来想怎样、看到什么。点「复制反馈内容」。
10. 粘到 QQ 群或仓库 Issue。别把 API Key 贴出去。

## 十三、常见问题

### 没配模型会怎样

不影响写内容、填记录、导出 Word。

用不了的是 AI 起草、AI 想题目、检索。

界面上显示「AI 不可用 · 未配置模型」，是提醒，不是坏了。

### AI 一直灰着、没反应

先看「设置 → 模型与检索 → API 管理中心」，Agnes 那行的开关开没开。显示「已停用」就是没开。

再点「连接测试」，看红字。

然后对地址：`https://apihub.agnes-ai.cn/v1`。

再看钥匙有没有粘全，模型页里那行是不是「已校验」、有没有「设为默认」。

### 导出的文件找不到

先翻系统默认的「下载」文件夹。

点了「另存为…」的，去你挑的那个位置找。

想不起来就再导出一次，这回挑桌面。

文件名里带课题名和材料名，搜一下也能找到。

导出完软件会提示存在哪，照着提示找最快。

### 备份口令忘了

找不回来。软件不保存口令，没有后门。

那份备份先留着，别删。

原数据还在的话，重新设个新口令，重新导一份。

### 网页版和电脑版数据不互通

想搬，用第十一节的导出和恢复，同一个口令。

清浏览器数据或卸载应用，本机那份会一起没。

API Key 只在自己设备上填。公用电脑别填。
