## 一、这个群是干什么的

研学帮 StudyMate 是个人开发的第三方研究性学习辅助工具，不是学校官方系统。
这个群只做四件事：

1. 发新版本、说明这版改了什么；
2. 收集 bug 与使用问题（截图 + 机型 + 版本号，越具体越好）；
3. 交流研究性学习的做法，比如开题怎么写、记录怎么记；
4. 收集功能建议。

**不做**：代写作业、代做课题、买卖成品报告。看到直接移出。

---

## 二、进群先看这三条

1. **软件在哪下**：群文件里的安装包为准。Windows 用 `setup.exe`，安卓用 `app-release.apk`。别人转发的包不要装。
2. **模型要自己配**：软件不自带任何 Key。打开「设置 → 模型服务」粘贴你自己的 API Key，拉取模型后**记得点一下启用开关**，顶栏胶囊显示模型名才算接通。
3. **数据只在你手机/电脑上**：没有账号、没有云端。换设备或清数据前，先在「设置 → 数据与备份」导出备份，丢了没法找回。

---

## 三、提问的正确姿势

发这四样，基本都能一次说清：

- 版本号（设置 → 关于，例如 `v1.0.1`）
- 机型 / 系统（例如 小米 14 / Android 15；或 Windows 11）
- 你点了什么、期望是什么、实际发生了什么
- 截图或录屏（涉及 Key 的地方先打码）

**不要在群里发 API Key、真实姓名、学校班级、访谈对象信息。** 看到了我会提醒，提醒两次还是发，就请出去了。

---

## 四、常见问题（先自查，能省一轮）

| 现象 | 处理 |
| --- | --- |
| 顶栏一直显示「未配置模型」 | 服务商保存后要打开启用开关；再不行重新拉一次模型列表 |
| 对话回「还没有可用的模型」 | 同上，或 Key 额度用完了 |
| 触发限流（429） | 软件会自动等约 1 分钟重试，不用管，别反复点 |
| 检查更新说没有可用更新源 | 仓库还没发布，以群文件和群公告为准 |
| 导出的 DOCX 打开错位 | 用 Word 打开看；WPS 老版本对表格支持差一些 |
| 手机上顶栏被状态栏盖住 | 已在新版本修；还出现就报机型和系统版本 |

## 五、版本与更新节奏

- 版本号形如 `1.0.1`：第一位大改版，第二位加功能，第三位修问题。
- 新版本先发群文件，群公告里写清楚改了什么。
- 不承诺更新频率。这是课余时间维护的项目，学业忙的时候会慢。

---

## 六、底线（说清楚免得误会）

- 软件里的 AI 只是草稿工具。**没有真实做过的调查、访谈、实验，不要写成已完成**；软件本身也会拦这种写法。
- 「（AI 模拟示例）」这类标识不要去掉，去掉了提交出问题自己承担。
- 「指导教师意见」「签字」由老师本人填，软件不代写、不代签。
- 本软件与福州鼓山中学及其管理部门无隶属、授权、合作或背书关系，群里的发言也不代表学校立场。
