# 隐私政策

最后更新：2026-11-02

研学帮 StudyMate 是本地优先的工具。下面写的是它实际做了什么，不是法律套话。

## 1. 数据存在哪

- 所有项目、报告、研究记录、来源、设置都存在**你自己的设备**上（浏览器 IndexedDB / 桌面端本地数据目录）。
- 开发者**没有服务器**，也**不收集**你的项目内容。
- 没有账号系统，没有云同步。

## 2. 什么时候会联网

只有这三种情况：

1. **你主动使用 AI 功能**：把当次需要的文本（项目信息、章节要求、已有正文片段）发给你自己配置的模型服务商。发什么由你点的那次操作决定。
2. **你主动检索资料**：向 OpenAlex / Crossref 发送检索关键词。
3. **检查更新**：从 GitHub Release 或仓库 JSON 读取版本信息（不携带项目内容）。

除此之外不会发起任何网络请求。**没有遥测，没有埋点，没有崩溃上报。**

## 3. API Key 怎么存

- 用 WebCrypto AES-GCM 加密后写入 IndexedDB。
- 设备主密钥以「不可导出」的 CryptoKey 形式存放。
- Key 不会进入日志、URL、Git 仓库、源码、构建产物。
- 界面与错误信息里一律脱敏显示。

**必须说清楚**：任何能在同一页面同源执行的代码（恶意浏览器扩展、被注入的脚本、开发者工具）都可以调用解密。
前端加密只能降低「明文被随手翻到 / 被备份文件带出」的风险，**无法抵御本机恶意软件或浏览器调试**。
不要在公用电脑上保存 Key。

加密备份（导出/导入）用你自设的口令经 PBKDF2-SHA256（210000 次）派生密钥。口令丢失无法恢复。

## 4. 你的权利

- **导出**：随时导出单份 DOCX、全部 ZIP 资料包、Markdown。
- **删除**：设置 → 数据 → 清空本地数据，会删除本设备上全部项目与配置。
- **不联网使用**：不配置 API 也能手写、填记录、导出文档。

## 5. 未成年人

本工具面向中学生。它不收集个人信息，但**项目内容里可能包含同学姓名**。请自行遵守学校规定与个人信息保护要求，报告里尽量脱敏。

## 6. 第三方

你使用的模型服务商、检索服务各有自己的隐私政策与计费规则。数据一旦发给他们，就受他们的条款约束，本工具无法控制。
