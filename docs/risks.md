# 风险清单

## 高

1. **AI 编造研究内容**（最致命）
   缓解：生成前证据闸门 + 生成后 `sanityCheck` + 导出强制模拟标识 + 无记录时拒绝生成「已完成」。
   残余风险：用户自己手动编造，工具无法识别。

2. **学校模板差异**
   缓解：四种报告结构来自真实表格；模板导入列为 M2。
   残余风险：其他学校字段不同，当前需要手动调整导出后文档。

3. **浏览器 CORS 导致部分服务商不可用**
   缓解：错误提示明确区分「网络失败 / CORS / Key 错误 / 限流」。桌面与安卓壳可绕开 CORS，Web 端不能。
   残余风险：Web 端某些国内服务商直接不可用，需改用其兼容中转或本地模型。

## 中

4. **API 费用失控**
   缓解：每日调用/金额上限、上下文压缩、缓存、按档位选模型、单任务调用上限。
   残余风险：用户把上限设得过大，或模型价格填错导致估算偏低。

5. **前端密钥保护有限**
   已如实说明，不宣称能抵御本机恶意软件。

6. **DOCX 兼容性未做真机全面测试**
   缓解：产物通过 OOXML 结构校验；TOC 需 Word 更新域。
   残余风险：WPS / 旧版 Word 对目录域、表格边框表现可能不一致，需人工核对。

## 低

7. **15 篇记录的冗余填写**
   缓解：阶段模板 + AI 起草 + 前序记录作为上下文。
   风险：连续生成易出现模板腔，需人工改写。

8. **OpenAlex / Crossref 速率限制**
   缓解：客户端节流（每分钟上限），失败如实提示，不重试轰炸。
