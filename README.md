## 这是什么

一个项目 = **一整套研究性学习交付物**：

| 交付物 | 数量 | 版式来源 |
| --- | --- | --- |
| 开题报告 | 1 | 学校《课题开题报告》表格 |
| 研究记录 | **15**（上学期 / 下学期可自定义拆分） | 学校《阶段性工作小结记录表》 |
| 中期报告 | 1 | 学校《课题中期检查报告》 |
| 结题报告 | 1 | 学校《结题报告》十章结构 + 参考文献 |

四份材料共享同一套项目事实（主题、成员、分工、计划、活动记录、数据、来源）。后一份继承前一份已确认的信息，避免重复填写与前后矛盾。

导出的是**真正的 Office Open XML `.docx`**（用 `docx` 库生成，不是把 HTML 改后缀）。

结题答辩另有**演示文稿工作台**：从项目页「交付与导出 → 生成答辩 PPT」进入，按「封面 → 为什么做 → 怎么做 → 过程与发现 → 局限与下一步 → 结尾」排页，导出真正的 `.pptx`（16:9、文字可继续编辑、带演讲备注）与配套讲稿 `.md`。生成分「演示策划 / 逐页撰写 / 演示终检」三步，过程、耗时与调用次数都看得见；每页标题、要点、顺序、口播词都能改，改动自动存本机。内容只取自项目里已有的报告、记录、数据集与来源，缺的写「待补充」，模拟内容保留「AI 模拟示例」标识；没配模型时可用离线模板生成。相关 4 个技能与 3 个助手在「开发者中心」里可查看和修改。

## 功能

### 建项目（小白化）

- 粘贴或导入教师要求 → 「让 AI 帮我分析要求」→ 逐项确认后应用
- 规则解析离线可用（学校 / 年级 / 班级 / 教师 / 时间 / 篇数 / 字数），AI 只做补空
- **指导教师姓名、成员姓名必须本人填写，AI 不猜、不编**

### 研究方式（可混合）

- 纯理论研究 / 实践研究 / AI 模拟实践
- AI 模拟内容全程带 `（AI 模拟示例）` 标识，导出时保留
- AI 工作模式：AI 辅助 / AI 主导辅助

### API 管理中心（设置 → API 管理中心）

**服务商**：名称、接口类型、Base URL、密钥、模型列表、请求参数、启用状态、默认状态。
同一服务商可创建多条配置，分别用于不同密钥、区域节点或本地部署，彼此独立。

- 适配器：OpenAI 兼容、Anthropic、Gemini、本地模型（Beta）。各适配器的**支持范围**直接标注在界面上：
  兼容仅指 `/chat/completions` 与 `/models` 两条路径，流式输出、工具调用、图像输入均未接入
- 连接测试分三段：**地址 → 鉴权 → 指定模型生成**。逐段返回结果，可区分地址错误、密钥无效与模型不可用
- 模型列表：自动尝试 `{base}/models`（Anthropic 为 `/v1/models`，Gemini 为 `/v1beta/models`，Ollama 回退 `/api/tags`）；
  接口不提供时提示手动录入，不阻塞配置流程
- **模型列表不等于可用性**：每个模型可执行一次真实生成校验，通过后标记「已校验」；未校验的模型不参与自动分配
- 支持搜索、收藏、设为默认、移除与手动录入；同步列表时保留已填单价、收藏与能力标注
- 能力标注（图像输入 / 工具调用 / JSON / 推理）仅开发者模式可见，只影响路由偏好，不会扩展实际接口能力

**分配与成本**：优先级为 手动指定 → Agent 指定 → 顶栏选择 → 规则 → 默认服务商。

- 规则按任务类型确定档位：记录与小结使用低成本模型，报告、规划与分析才使用高性能模型
- 相同请求在 TTL 内复用结果，并发重复请求合并为一次调用，超长上下文自动压缩（保留最近 8 条）
- 预算：每日请求次数与金额双上限，达到 80%（可调）时提醒；触顶后**暂停并请求确认**，不会静默超支
- 统计：请求次数、失败数、Token、耗时与估算成本，可按模型与 Agent 分组；同时记录缓存命中与请求合并次数
- 余额仅在服务商提供官方接口时展示。当前各适配器均无可用余额接口，界面明确标注「不显示」，不以估算值替代

**密钥**：AES-GCM 加密后存储于本机 IndexedDB，设备主密钥不可导出；仅通过请求头传递，不附加于 URL。
支持加密导出（口令经 PBKDF2 210k 次派生，文件仅含密文）、加密导入与单条删除。
错误提示统一脱敏：即使服务商在报错中回显密钥，也会被替换为 `***`。
**Web 环境限制已在界面说明**：同源脚本（浏览器扩展、注入脚本、调试工具）均可调用解密接口，浏览器端加密无法抵御本机恶意程序。

**本地模型（Beta）**：提供 Ollama 与 LM Studio 的分步接入说明（安装、模型下载、地址与模型名称填写）、连接测试与地址复制。
界面明确三点：安卓端推理受设备性能限制；局域网地址可能被同网段设备访问；所有请求由本机直连，不依赖开发者服务器。

### 检索与来源（多 Provider）

设置 → 检索服务里可以同时配多个来源，按优先级各自限流、轮转合并、去重：

- **免 Key 的公开学术接口**：OpenAlex、Crossref、arXiv、Semantic Scholar，默认开启
- **通用网页检索**：Tavily、Brave、Serper、博查、SearXNG，需自备 Key
- **能力标签**：通用网页 / 学术元数据 / 近期新闻 / 指定域名 / 网页正文 / 本地文件；检索时按能力命中，而不是按名字
- **组合检索**：优先级排序 → 并发（各自节流）→ 轮转合并 → 去重（DOI 优先，其次 URL，最后规范化标题）
- **限定域名**：客户端兜底过滤；**网页正文**：只抓前几条，失败时保留摘要并如实报错
- **本地文件**：导入 txt / md / csv / log（单文件 2MB 内），本机全文匹配，不上传

来源条目记录：标题 / 作者 / 机构 / 发布日期 / URL / DOI / 检索时间 / 摘要 / 来源类型 / 核验状态 / 检索词 / 来源服务 / 正文摘录 / 备注，以及**关联报告段落**——勾选后生成该段落时会优先引用这些来源。

检索结果默认「待核实」，不会自动当事实。DOI 只做格式校验，能否解析以出版方为准。

### 免费 API 指引（设置 → 免费 API 指引）

按 AI 模型 / 搜索 / 学术检索 / 本地模型 / 文档工具分类，每条服务给：官网、注册入口、免费额度、是否需要信用卡（未知就写未知）、取 Key 步骤、Base URL、模型示例、配置步骤、限制说明、最后核实日期，以及一键复制配置示例。

- 目录可从远端 JSON / Markdown 加载，失败时回落到本机缓存与内置清单
- 额度与条款随时会变，页面上的「最后核实日期」只代表当时查到的情况，以官方页面为准，不承诺永久免费

### 缺材料时：留白 / 写满

默认留白：缺少事实就写「待补充：缺什么」，不编数据、访谈或实验结果。

需要先把篇幅撑起来时，可在 设置 → 个性化（或报告页右侧栏）切到「写满再核对」：

- 放宽的只有篇幅：推断、过渡与分析性表述句末加「（推断，需核实）」
- 具体数字、人名、日期、访谈原话、文献出处仍写成 `______（需补充实测数据）`
- 仍禁止虚构参考文献、作者、DOI；末尾自动附免责声明，提示逐条核对后再提交
- 「没有任何研究记录」等缺口在该模式下降级为提醒，成员名单、课题名这类结构性缺失仍然阻断

### 设置与引导

- 设置首页直接改：主题 / 字体 / 动效 / 通知 / 语音 / 预算 / 记忆 / 常用语，一屏内完成，不再点进点出
- 二级页只留需要整屏的：账号、API 管理中心、检索服务、免费 API 指引、数据与备份、订阅、帮助
- 开发者选项收进 设置 → 其他设置 → 开发者选项，普通使用看不到
- 引导首屏是一整屏「你好」，然后进入研学帮介绍；隐私政策 / 用户协议 / 声明**必须拉到底并等 3 秒**才能继续，勾选只是「同意」，读没读是另一件事
- 引导第 4~6 步（外观、偏好、接入模型）可跳过；「去配置模型」先保存已选项再跳转
- 设置里支持「重新引导」，只回看流程，不清空数据、不重复计时
- 条款有独立阅读页（`/legal/privacy`、`/legal/terms`、`/legal/statement`、`/legal/license`），带目录锚点与版本号，不再跳回引导

### 四份材料（按学校下发的表格还原）

内置模板不是自己编的格式，是把学校下发的文件逐行搬进软件，**行列、列宽、标签文字、字号字体、页边距都不改**：

| 材料 | 原文件 | 结构 |
| --- | --- | --- |
| 开题报告 | 鼓山中学研究性学习课题开题报告.docx | 8 行 / 7 列网格；课题题目、成员、组长、指导教师、班级、简要背景说明、目的和意义、主导课程、相关课程、活动计划、指导教师意见（签名 + 年月日） |
| 阶段性记录表 | 研究性学习阶段性记录表.doc | 6 行 / 2 列；起迄时间、本阶段主要研究目标、本阶段主要研究工作、阶段性成果、工作小结、下阶段研究工作安排，标题下有「第 __ 研究阶段　记录人　记录时间」 |
| 中期检查报告 | 研究性学习中期检查报告模版.doc | 7 行 / 6 列；课题名称、组长、记录人、起止时间、进展情况、问题及对策（保留原表括注）、自我评定、成员表现、下一阶段要点 |
| 结题报告 | 研究性学习结题报告（范例参考）.doc | 十章长文，一、…十、；正文四号宋体、标题加粗、首行缩进 2 字符、1.5 倍行距 |

- 学校下发的《备选课题》168 条也搬进了软件：新建项目时可搜索、按学科筛选，也可以自己定题
- 章节可改名、增删、上下移；也可导入自己的 DOCX / Markdown 模板识别标题后套用
- **缺真实信息就不写**：立项前先做缺口检查，缺关键材料直接不允许生成；空格子写「（本节尚未填写）」
- 「指导教师意见」栏永不代写，只留签名与日期
- 结题报告默认不加封面目录（范例是纯长文）；需要时在导出面板勾「加封面和目录」

### 智能模式与开发者中心（双档）

**普通模式**在项目页只出现七个按钮，不说「Agent」这个词：智能规划 / 资料研究 / 任务分工 / 报告生成 / 内容审核 / 格式检查 / 项目自动推进。前六个直接调对应 Agent 干一步；「项目自动推进」打开工作流面板。

**工作流**内置 17 步标准流程：分析课题 → 用户确认计划 → 搜索资料 → 确认来源 → 研究设计 → 确认方法 → 分工 → 确认分工 → 立项报告 → 审核 → 确认 → **真实记录守卫** → 中期报告 → 审核 → 结题报告 → 最终审核 → 导出 DOCX。

- 三种范围：当前报告生成 / 当前阶段自动完成 / 全项目推进
- 可暂停、继续、取消、失败重试；每次运行单独限制调用次数与预算，超出即停，不会偷偷继续
- **没有真实活动记录，流程推进不进中期报告**——守卫检查「已确认 + 真实开展」的记录数，模拟内容不算
- 阶段自动完成时中间的确认门自动通过并记日志，最后一道门仍然要人

**开发者中心**（设置 → 其他设置 → 开发者选项）分五页：

- **Agent**：内置 9 个（项目规划、资料研究、研究设计、数据分析、报告写作、格式检查、引用核验、内容审核、总审核）。可自定义新 Agent（提示词、指定模型、权限、执行顺序、超时、最大循环、预算），内置的可改可恢复默认
- **Skills**：内置研究规范、四大报告、问卷、访谈提纲、实验方案、数据分析、图表、文献整理、引用检查、DOCX 排版、学术表达润色。支持导入自定义 Skill——导入前先摆出来源与权限，带可执行字段（code/script/eval）的一律拒收，只接受纯声明式内容；本软件不执行任何外部代码
- **工作流**：可视化编辑器，泳道按阶段分组，步骤可排序、停用、改超时/循环/预算；确认门与记录守卫不可删除
- **提示词**：查看每个 Agent 的系统提示词、复制、小成本试跑（限 2 次调用）、缓存命中统计与清空
- **日志与用量**：工作流执行记录（逐步展开看产出）、最近调用明细、失败率与平均耗时

### 研究日志

界面按记录表的六个格子填：起迄时间 / 本阶段主要研究目标 / 本阶段主要研究工作 / 阶段性成果 / 工作小结 / 下阶段研究工作安排，外加记录人、记录时间。

活动名称、阶段名称、地点、参与成员、使用材料、附件只在本软件存档——记录表里没有这些栏，导出时不硬塞进去。
每篇记录可标「真实记录 / 用户提供 / AI 模拟示例」，模拟内容在界面与导出文件中都带标识。

### 导出

- 单份 DOCX、研究记录合集 DOCX（每篇一页）、ZIP 项目资料包、Markdown
- 真 OOXML：表格网格与行高按原表写进 `w:tblGrid` / `w:trHeight`，单元格合并按原表 `w:gridSpan`；宋体 + Times New Roman
- 结题可选封面与目录域（Word 域，首次打开需右键「更新域」）
- 含模拟内容的文档，文首自动加提示框；正文保留「（AI 模拟示例）」标记

### UI

- 浅色 / 深色 / 跟随系统（默认跟随）；内置 HarmonyOS Sans，也可切回系统字体
- **电脑与手机同一套导航**（`src/nav.ts` 是唯一清单，侧栏与抽屉渲染同一个组件），功能不再两头不一样
- **所有页面切换都有左右方向动画**：前进时新页从右进入、旧页向左让位，返回时反向；路由页、设置二级页、引导每一步、欢迎屏 → 引导主体都走同一套
- 全局动效开关（默认开）：页面切换、抽屉、折叠、流式文字、按压反馈。关掉才统一降级为无动画；系统开启「减少动态效果」时只压缩时长，不会把动画归零
- 设置页改为单页优先：能当场改的（主题 / 字体 / 动效 / 通知 / 语音 / 预算 / 记忆）直接放在首页，其余进二级页
- 语音只使用自然音色（Neural / Natural / Enhanced），本机没有就不启用——宁可没有，也不放机械音
- 默认头像用系统式人形剪影，不用姓名首字拼图案
- 账号安全：头像（可上传，本地压缩）、昵称（首页称呼同步）、未成年人模式（监护人 4–6 位数字密码）、设备与授权管理、账号注销
- 一键清档：三次确认（体验词 + 勾选 + 本机随机验证码 + 8 秒倒计时），不可连点蒙过
- 普通模式五个入口（智能助手 / 资料研究 / 任务分工 / 报告生成 / 报告审核）
- 开发者模式：Agent 提示词、Skills、模型指定、执行日志、用量

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 单元测试
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览 dist
```

环境要求：Node ≥ 20（本机 22 实测）。

第一次打开是引导页，需要逐条确认四项声明后才能进入。

### 接一个模型

1. 设置 → API 管理中心 → 选择一个预设（如 DeepSeek）
2. 填写 API 密钥 → 保存
3. 点击「同步模型」，或在「模型」页手动录入模型名称
4. 点击「连接测试」：地址、鉴权、指定模型生成三段依次执行

未配置模型时，手写内容、填写记录与导出 DOCX 仍可正常使用，AI 生成与检索功能显示为不可用。
